# Predictive Maintenance HVAC

Analyze and clean HVAC sensor data for predictive maintenance and operational insights.

## Tasks Performed
- Data inspection
- Missing value analysis
- Data cleaning
- Handling missing sensor readings
- Datetime processing
- HVAC sensor analysis

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Dataset Features
- Timestamp
- CO2 sensor readings
- HVAC operational data
- Energy-related parameters
